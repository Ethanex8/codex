# Problem 1.25

!!! info "Textbook Reference"
    - **Textbook**: *Classical Mechanics* (John R. Taylor)
    - **Chapter**: 1 — Newton's Laws of Motion
    - **Problem**: 1.25
    - **Difficulty**: $\star$
    - **Topic**: First-Order Differential Equations

## Problem Statement

Find the general solution of the first-order differential equation:

$$
\frac{df}{dt} = -3f
$$

for an unknown function $f(t)$. How many arbitrary constants does the general solution contain?

## Solution

### Separation of Variables

Rewriting the differential equation to separate the variables $f$ and $t$:

$$
\frac{df}{f} = -3\, dt
$$

Integrating both sides:

$$
\int \frac{1}{f}\, df = \int -3\, dt
$$

$$
\ln|f| = -3t + C_1
$$

where $C_1$ is an arbitrary constant of integration.

### General Solution

Exponentiating both sides:

$$
|f(t)| = e^{-3t + C_1} = e^{C_1} e^{-3t}
$$

Defining $C = \pm e^{C_1}$ (with $C = 0$ accounting for the trivial solution $f(t) \equiv 0$):

$$
f(t) = C e^{-3t}
$$

where $C$ is an arbitrary real constant.

### Number of Arbitrary Constants

The general solution contains exactly one arbitrary constant ($C$).

This illustrates the general theorem that the solution to an $n\text{th}$-order differential equation contains $n$ arbitrary constants ($n = 1$).
